      Under the hood

      What one turn actually does

      No agent framework, no vector database. A router, a store, and a guard.

      1. 1

        Classify the intent

        CASUAL, PERSONAL, CODING, SEARCH, RECALL, SAVE, COMMAND or REMINDER. The label decides everything downstream.

      2. 2

        Assemble the context

        Recent turns from the store, durable facts, the project brain, screen context, error-intelligence hints, the relationship layer.

      3. 3

        Route to a model

        Cheap model for trivia, heavy model for code and research. Rate limits are per model, so the small one absorbs the background work.

      4. 4

        Sanitize and guard

        Leaked chain-of-thought is stripped, brevity is enforced on sentence boundaries, and the output gate has the last word.

      5. 5

        Write it back

        Everything lands in SQLite, so the next turn — tomorrow's turn — still remembers.

      Run the real thing

      Four commands and a double-click

      # 1 — Python deps
pip install -r requirements.txt

# 2 — Frontend deps
cd frontend && npm install && cd ..

# 3 — Keys: create .env with GROQ_API_KEY=...

# 4 — Run
python server.py            # backend on 127.0.0.1:8760
cd frontend && npm run dev   # Vite + Electron

      Or just double-click AURA.bat

      It builds the frontend on first run, launches Electron, and Electron boots the server itself. CREATE_DESKTOP_SHORTCUT.bat puts it on your desktop with the black-hole icon.

      Hosting this page yourself

      The site and its demo API ship with the repo. python server.py serves both — the landing page at /, the sandboxed demo at /web/api/*.

      Requirements

      Python 3.11+, Node 18+, and a Groq or OpenRouter key. Windows is the tested path; the backend is platform-neutral.
